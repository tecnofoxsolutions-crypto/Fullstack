# Matriz de Requerimientos de Software (Anexo 2 y Anexo 3)
**Proyecto:** PixelVault - Tienda de Videojuegos Físicos (Estilo Steam + 16-Bit Arcade)  
**Asignatura:** DSY1104 - Programación Web / Desarrollo Frontend  
**Evaluación:** Evaluación Parcial 1 (30%)  
**Estructura del Proyecto:** 11 archivos HTML (`index.html`, `catalogo.html`, `carrito.html`, `login.html`, `registro.html`, `nosotros.html`, `contacto.html`, `blog.html`, `usuarios.html`, `pedidos.html`, `historial.html`) + 1 CSS (`css/estilos.css`), con scripts JavaScript integrados en cada vista siguiendo el estándar de `proyecto_front`.  

Esta planilla sigue el estándar oficial solicitado en la **Planilla de Requerimientos (Anexos 2 y 3)** del ramo, clasificando los requisitos según su tipología, clasificación de ingeniería de software, actores involucrados, descripción y estado para la Entrega 1.
